# Concatenates objects into a vector or list

This function is similar to the R base function 'c'.

## Usage

``` r
cDS(x.names)
```

## Arguments

- x.names:

  a character vector of object names to concatenate.

## Value

a vector or list

## Details

Unlike the R base function 'c' on vector or list of certain length are
allowed as output
