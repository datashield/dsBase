# @title lexisDS3

The third serverside function called by ds.lexis.

## Usage

``` r
lexisDS3()
```

## Value

Data frame with \`messageobj\` object

## Details

This is an assign function that simplifies the returned output from
ds.lexis. Specifically, without lexisDS3 the output consists of a table
within a list, but lexisDS3 converts this directly into a dataframe. For
more details see the extensive header for ds.lexis.
