# Computes the square root values of the input variable

This function is similar to R function `sqrt`.

## Usage

``` r
sqrtDS(x)
```

## Arguments

- x:

  a string character, the name of a numeric or integer vector

## Value

the object specified by the `newobj` argument of `ds.sqrt` (or default
name `sqrt.newobj`) which is written to the server-side. The output
object is of class numeric or integer.

## Details

The function computes the square root values of an input numeric or
integer vector.
