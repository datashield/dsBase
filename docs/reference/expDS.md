# Computes the exponential values of the input variable

This function is similar to R function `exp`.

## Usage

``` r
expDS(x)
```

## Arguments

- x:

  a string character, the name of a numeric or integer vector

## Value

the object specified by the `newobj` argument of `ds.exp` (or default
name `exp.newobj`) which is written to the serverside. The output object
is of class numeric.

## Details

The function computes the exponential values of an input numeric or
integer vector.
