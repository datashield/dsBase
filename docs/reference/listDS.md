# Coerce objects into a list

this function is similar to R function 'list'

## Usage

``` r
listDS(x.names = NULL, eltnames = NULL)
```

## Arguments

- x.names:

  a character vector of object names to coerce into a list.

- eltnames:

  a character vector, the names of the elements in the list.

## Value

a list

## Details

Unlike the R function 'list' it takes also a vector of characters, the
names of the elements in the output list.
