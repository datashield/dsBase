# Returns the levels of a factor vector

This function is similar to R function `levels`.

## Usage

``` r
levelsDS(x)
```

## Arguments

- x:

  a character string, the name of a factor vector

## Value

a list with one element: `Levels` (the factor levels present in the
vector)

## Details

The function returns the levels of the input vector or list.
