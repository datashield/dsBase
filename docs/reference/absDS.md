# Computes the absolute values of the input variable

This function is similar to R function `abs`.

## Usage

``` r
absDS(x)
```

## Arguments

- x:

  a string character, the name of a numeric or integer vector

## Value

the object specified by the `newobj` argument of `ds.abs` (or default
name `abs.newobj`) which is written to the serverside. The output object
is of class numeric or integer.

## Details

The function computes the absolute values of an input numeric or integer
vector.
