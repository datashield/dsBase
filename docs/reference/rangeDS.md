# returns the minimum and maximum of a numeric vector

this function is similar to R function `range` but instead to not return
the real minimum and maximum, the computed values are multiplied by a
very small random number.

## Usage

``` r
rangeDS(x)
```

## Arguments

- x:

  a character string, the name of a numeric or integer vector

## Value

a numeric vector which contains the minimum and the maximum values of
the vector
