# lexisDS1

The first server-side function called by ds.lexis.

## Usage

``` r
lexisDS1(exitCol = NULL)
```

## Arguments

- exitCol:

  a character string specifying the variable holding the time that each
  individual is censored or fails

## Value

List with \`max.time\`

## Details

This is an aggregate function. For more details see the extensive header
for ds.lexis.
